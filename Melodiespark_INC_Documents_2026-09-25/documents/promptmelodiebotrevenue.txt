| `BLOCKED` | Cannot proceed until dependency resolved | Blocked | Unblock dependency |
| `PENDING` | Submitted to external system | Pending | Wait, do not act again |
| `CONFIRMED` | External system confirmed | Confirmed | Read |
| `FAILED` | External system rejected | Failed | Investigate, allow retry |
| `REJECTED` | Human reviewer rejected | Rejected | Edit and resubmit |
| `COMPLETED` | Workflow finished and evidence stored | Completed | Read |
| `READ_ONLY` | Display only, no side effects | Read-only | Inspect |

**Rule:** "Revenue earned," "transaction succeeded," "customer acquired," "contract signed" can only be displayed with `CONFIRMED` or `VERIFIED` evidence attached.

### 3.3 Golden Path: one customer → one payment → one delivered result

2. **Qualify** — agent drafts lead score; human reviews if score crosses threshold.

5. **Invoice** — issued only after acceptance.
6. **Payment** — Stripe Checkout or Payment Link; webhook creates `payment_event` with `status=CONFIRMED` only after Stripe signature verification.
7. **Fulfill** — service delivered against acceptance criteria; completion evidence uploaded.
8. **Receipt** — invoice marked `PAID`; customer email receipt; audit log entry.
9. **Support** — SLA timer starts; ticket creation permitted within entitlement window.
10. **Closeout** — service completion certificate generated; case-study eligibility evaluated (only with explicit re-consent).

**Failure states documented for each step:** consent missing, payment failed, refund requested, chargeback opened, dispute raised, acceptance not provided, evidence missing.

### 3.6 Matrix Engine (the "fractal loop" you described, made real)

This is the **Phoenix** workflow engine. The "polygon sacred geometry" naming is not a compute claim — it's a visual metaphor for a balanced state machine with many parallel, terminating loop conditions. The engine is **durable, idempotent, and stop-bounded**.

**Workflow state machine:**

```
INIT → CLASSIFY → GUARD_CHECK
   ↓
DRAFT → REVIEW → AWAITING_APPROVAL
   ↓
APPROVED → EXECUTE → PENDING
   ↓
CONFIRMED → EVIDENCE_ATTACHED → COMPLETED
   ↘ FAILED / REJECTED / BLOCKED → DLQ
```

**Per-task guarantees:**

- `idempotency_key` (UUID) prevents duplicate side effects.
- `max_attempts` (default 3) with exponential backoff.
- `timeout` (default 5 min, configurable).
- `approval_required` flag — `true` for any financial, contractual, contact, or data-deletion action.
- `evidence_required` flag — `true` for any "completed" or "confirmed" transition.
- `stop_conditions` — failure, rejection, max attempts, or human abort.

**Loop cycles (bounded, not infinite):**

- `LEAD_NURTURE_LOOP` — max 5 touches, then human review.
- `INVOICE_FOLLOWUP_LOOP` — D+1, D+7, D+14, D+30, then escalate.
- `EVIDENCE_COLLECTION_LOOP` — max 3 attempts, then `BLOCKED` with human task.
- `KYC_REVIEW_LOOP` — max 2 attempts, then `REJECTED`.
- `WEBHOOK_RETRY_LOOP` — bounded by Stripe retry policy + max 5 local retries.

**No infinite loops. No "speed of light" claims. No "pop-up revenue."** Every loop has a stop condition, a budget, and an evidence requirement.

## 5. Revenue Ledger & Withdrawal System

### 5.1 Money only flows in from verified events

**Allowed inbound sources:**
- Stripe webhook `charge.succeeded` (signature verified) → `payment_event` row, status `CONFIRMED`.
- Marketplace settlement report from a reviewed marketplace provider → `payment_event` row.
- Manual bank reconciliation with two human approvals + bank statement upload.

**Prohibited sources (must be `BLOCKED` if attempted):**
- Direct agent writes to `payment_event`.
- "Inferred" or "estimated" revenue.
- "Projected" revenue.

### 5.2 Internal ledger (double-entry style)

```
account(id, type, name, currency, owner_type, owner_id)
  # types: asset, liability, revenue, expense, tax, reserve
journal_entry(id, at, memo, source, source_id, evidence_hash)
journal_line(id, entry_id, account_id, debit, credit, currency)
```

**Account classes (always separate):**
- `customer_funds` (liability — money held on behalf of customers)
- `operating_cash` (asset — company funds)
- `tax_reserve` (liability — set aside for taxes)
- `refund_reserve` (asset — backing outstanding refund obligations)
- `chargeback_reserve` (asset — backing chargebacks)
- `revenue_recognized` (revenue)
- `processing_fees` (expense)
- `payable_balance` (liability — to founders/contractors, when eligible)

### 5.3 Withdrawal flow (read-only agents, human approvals, external signer)

```
1. User requests withdrawal
   → request stored with status PENDING_APPROVAL
2. Finance review (human #1)
   → verifies: identity, allowlisted recipient, limits, no holds
3. Founder approval (human #2, dual-control)
   → treasury policy engine re-validates
4. External signer (hardware key) signs
   → for fiat: bank-validated transfer; for crypto: external wallet
5. Broadcast/submit
   → status PENDING
6. Provider or chain confirms
   → status CONFIRMED with receipt hash
   → journal entries posted
```

**States:** `PENDING_APPROVAL`, `APPROVED_H1`, `APPROVED_H2`, `AWAITING_EXTERNAL_SIGNATURE`, `PENDING`, `CONFIRMED`, `FAILED`, `REJECTED`, `HELD` (suspicious activity), `REVERSED` (chargeback/fraud).

**For crypto withdrawals from MetaMello Treasury specifically:**
- Recipient must be on allowlist.
- Chain must be allowlisted.
- Transaction must be simulated.
- External hardware signer required.
- Receipt hash + explorer link recorded.
- "Success" only after at least 1 chain confirmation; recommend waiting for safe confirmations per chain (e.g. 12 for ETH L1).

### 5.4 Withdrawal display rule (mirrors the section 1 rule)

> Until a withdrawal is `CONFIRMED` by the payment provider or by on-chain receipt with the expected hash, the UI must show `PENDING` or `AWAITING CONFIRMATION`. Never show "Funds arrived" prematurely.

### 5.5 Disclosures (required on every finance screen)

- "Crypto asset values are volatile. Past performance does not indicate future results."
- "Transactions may be irreversible once confirmed."
- "Network and smart-contract risks apply."
- "This dashboard is informational; no investment, tax, or legal advice is provided."

### 6.5 Checkout & webhook flow

1. User clicks "Buy Securely."
2. Client `POST /api/checkout/session` with `{ priceId, quantity }`.
3. Server validates price exists, product is `available`, creates Checkout Session with `success_url`, `cancel_url`, `metadata`.
4. Client redirects to Stripe.
5. Stripe sends `checkout.session.completed` → `/api/webhooks/stripe`.
6. Server verifies signature using `STRIPE_WEBHOOK_SECRET`, then inserts `payment_event` (status `PENDING`), then on `charge.succeeded` updates to `CONFIRMED`.
7. Fulfillment workflow triggered (digital: instant access token; service: onboarding email + SOW request).

**Never** mark an order paid from the success-URL redirect alone. Webhook is the source of truth.

### 6.6 Edge cases

- Price not found → button disabled, tooltip "Pricing unavailable, contact sales."
- Product retired → shows `Retired`, no buy button.
- Subscription cancellation → instructions in account + email; no surprise charges.
- Webhook signature invalid → 400, log, alert.
- Duplicate webhook → idempotency via `provider_event_id`.
- Refund requested → `refund` row created, dual-approval for amount > threshold, customer notified.

### 6.7 Accessibility checklist (WCAG 2.2 AA)

- Color contrast ≥ 4.5:1 for text, 3:1 for UI.
- All interactive elements keyboard-reachable; visible focus rings.
- Forms have labels, error messages tied via `aria-describedby`.
- Modals trap focus, close on `Esc`, return focus on close.
- Reduced-motion media query respected.
- `prefers-color-scheme` not used to hide info; dark mode is on by default but light mode is equivalent.
- Images have meaningful `alt`; decorative ones use `alt=""`.

### 8.2 Action classes

- `READ` — no side effects.
- `DRAFT` — produces artifact, not yet sent.
- `PROPOSE` — submits for human review.
- `EXECUTE` — performs a non-financial, non-contact side effect, requires approval.
- `SEND_MESSAGE` — sends external communication, requires approved draft + consent on file.
- `SIGN_CONTRACT` — human only.
- `SPEND` / `TRANSFER` — human only, with external signer.

### 8.3 Model routing policy

- Classify task → privacy tier (PUBLIC, INTERNAL, PII, SENSITIVE) → select model within budget.
- Strip PII before sending to lower-trust models; use redaction layer.
- Log: trace ID, task class, model, prompt hash (not full prompt if it contains PII), output hash, latency, cost, evaluator score.
- Fallback model defined; circuit breaker on error rate.

### 8.4 Prompt injection defenses

- Untrusted content isolated into a separate "context" message.
- Tool calls only from system role.
- Output schema validation before any side effect.
- Citation required for factual claims; without citation → `UNVERIFIED` label.

- [ ] The `payment_event` row exists with `status=CONFIRMED`.

- [ ] The customer/quote is not flagged as fraudulent.
- [ ] No refund or chargeback supersedes the event at display time.
- [ ] The total displayed equals the verified sum (no rounding up, no projection).

For every "customer acquired" claim:

- [ ] `customer` row exists.

- [ ] On-chain `transactionHash` recorded.

- [ ] Provider or chain `CONFIRMED` state with receipt.

- [ ] Recipient matches approved recipient.
- [ ] Dual-approval IDs stored.
- [ ] Journal entry posted.
- [ ] No fraud hold active.

## 14. What this blueprint deliberately does **not** do

To be unambiguous about what this is and isn't, the following are explicitly **out of scope** unless a future, separately-gated, jurisdictionally-cleared implementation is built:

- **Autonomous revenue generation.** No software can guarantee revenue.
- **Autonomous crypto transfers from MetaMello Treasury.** Disabled by default; requires allowlist, dual-approval, external signer, and a separate activation gate.
- **"Mining" MA Token / Karma Power Point by running this app.** They are off-chain points with no monetary value and no exchange pathway.
- **Automatic swap from MA Token to ETH/USDT/BTC.** Not implemented; would require KYC, custody, exchange compliance, securities analysis, and licenses.
- **80,000 "bots" generating income.** Not a real architecture; real bot swarms do not produce legal revenue. The only legitimate bots are bounded automation tasks inside Phoenix, with stop conditions and approval gates.
- **Pop-up "earnings" or fake popups.** Revenue displays require verified evidence; "success" requires provider or chain confirmation.
- **Synthetic / fake / demo / placeholder data presented as real.** All "current values" must be either verified, or clearly labeled `UNVERIFIED` or `DRAFT`.

contract MaToken is 
    ERC20,

    ERC20Permit, 
    AccessControl,

    bytes32 public constant MINTER_ROLE = keccak256("MINTER_ROLE");
    bytes32 public constant TREASURY_ROLE = keccak256("TREASURY_ROLE");
    bytes32 public constant BOT_REVENUE_ROLE = keccak256("BOT_REVENUE_ROLE");
    bytes32 public constant KARMA_ENGINE_ROLE = keccak256("KARMA_ENGINE_ROLE");

    uint256 public constant MAX_SUPPLY = 1_000_000_000 * 10**18;
    uint256 public constant INITIAL_SUPPLY = 100_000_000 * 10**18;

    uint256 public karmaConversionRate = 100;
    uint256 public botRevenueShareBps = 500;
    uint256 public treasuryReserveBps = 1000;

    mapping(address => uint256) public karmaPoints;
    mapping(address => uint256) public lifetimeKarmaEarned;
    mapping(address => uint256) public totalRevenueGenerated;
    mapping(address => bool) public verifiedBots;
    mapping(address => bool) public verifiedServiceProviders;
    mapping(address => GoodDeed[]) public deedHistory;

    struct GoodDeed {
        string category;
        string description;
        uint256 karmaAwarded;
        uint256 tokensEarned;
        uint256 timestamp;
        address verifier;
        bool fulfilled;
    }

        uint256 amount;
        string productId;
        string serviceId;

        bytes32 transactionHash;
    }

    event KarmaAwarded(

        uint256 karmaPoints,

        string deedCategory
    );
    event RevenueGenerated(
        address indexed bot, 
        uint256 amount, 
        string productId
    );
    event TreasurySync(
        address indexed treasury, 
        uint256 amount, 
        uint256 timestamp
    );
    event BotRegistered(address indexed bot, uint256 timestamp);
    event ServiceProviderVerified(address indexed provider);
    event KarmaConverted(

        uint256 tokensReceived
    );
    event DeedFulfilled(
        address indexed user, 
        uint256 deedIndex,

    );

    constructor(
        address _treasury
    ) ERC20("Ma Token", "MA") ERC20Permit("Ma Token") {
        require(_treasury != address(0), "Invalid treasury");

        _grantRole(DEFAULT_ADMIN_ROLE, msg.sender);
        _grantRole(MINTER_ROLE, msg.sender);
        _grantRole(TREASURY_ROLE, _treasury);

        uint256 treasuryAllocation = (INITIAL_SUPPLY * treasuryReserveBps) / 10000;
        uint256 circulatingSupply = INITIAL_SUPPLY - treasuryAllocation;

        _mint(_treasury, treasuryAllocation);
        _mint(msg.sender, circulatingSupply);
    }

    function registerBot(
        address _bot
    ) external onlyRole(DEFAULT_ADMIN_ROLE) {
        require(_bot != address(0), "Invalid bot address");
        require(!verifiedBots[_bot], "Bot already registered");
        verifiedBots[_bot] = true;
        _grantRole(BOT_REVENUE_ROLE, _bot);
        emit BotRegistered(_bot, block.timestamp);

    function verifyServiceProvider(
        address _provider

        verifiedServiceProviders[_provider] = true;

        address _user,
        uint256 _karmaAmount,
        string calldata _category,
        string calldata _description
    ) external onlyRole(KARMA_ENGINE_ROLE) whenNotPaused nonReentrant {
        require(_user != address(0), "Invalid user");
        require(_karmaAmount > 0, "Karma must be positive");

        karmaPoints[_user] += _karmaAmount;
        lifetimeKarmaEarned[_user] += _karmaAmount;

        uint256 tokensEarned = (_karmaAmount * 10**18) / karmaConversionRate;
        require(
            totalSupply() + tokensEarned <= MAX_SUPPLY, 
            "Max supply exceeded"
        );

        _mint(_user, tokensEarned);

            description: _description,
            karmaAwarded: _karmaAmount,
            tokensEarned: tokensEarned,
            timestamp: block.timestamp,
            verifier: msg.sender,
            fulfilled: true
        }));

        emit KarmaAwarded(_user, _karmaAmount, tokensEarned, _category);
    }

        uint256 _karmaAmount
    ) external whenNotPaused nonReentrant {
        require(karmaPoints[msg.sender] >= _karmaAmount, "Insufficient karma");
        require(_karmaAmount > 0, "Must convert positive amount");

        karmaPoints[msg.sender] -= _karmaAmount;
        uint256 tokensToMint = (_karmaAmount * 10**18) / karmaConversionRate;

        require(
            totalSupply() + tokensToMint <= MAX_SUPPLY, 
            "Max supply exceeded"
        );

        _mint(msg.sender, tokensToMint);
        emit KarmaConverted(msg.sender, _karmaAmount, tokensToMint);
    }

    }

        _transfer(msg.sender, _treasury, _amount);
        emit TreasurySync(_treasury, _amount, block.timestamp);
    }

    }

        return revenueHistory.length;

        uint256 tokenBalance,
        uint256 deedCount

            lifetimeKarmaEarned[_user],
            balanceOf(_user),

pragma solidity ^0.8.20;

import "@openzeppelin/contracts/access/AccessControl.sol";

contract KarmaPowerPoint is AccessControl, ReentrancyGuard, Pausable {
    bytes32 public constant VERIFIER_ROLE = keccak256("VERIFIER_ROLE");
    bytes32 public constant BOT_ROLE = keccak256("BOT_ROLE");

    IMaToken public maToken;

    enum DeedCategory {
        ENVIRONMENT,
        SOCIETY,
        EDUCATION,
        HEALTH,
        SPIRITUALITY,
        TECHNOLOGY,
        ECONOMY,
        GOVERNANCE,
        COMMUNITY,
        CHARITY
    }

    enum AscensionTier {
        INITIATE,
        SEEKER,
        GUARDIAN,
        CHAMPION,
        MASTER,
        GRANDMASTER,
        LEGEND,
        MYTHIC,
        DIVINE,
        APEX
    }

    struct UserProfile {
        uint256 totalKarma;
        uint256 currentSeasonKarma;
        AscensionTier tier;
        uint256 deedsCompleted;
        uint256 contractsFulfilled;
        uint256 revenueContributed;
        uint256 streak;
        uint256 lastActivityTimestamp;
        uint256 seasonMultiplier;
        bool isActive;
    }

    struct ServiceContract {
        uint256 id;
        address provider;
        address beneficiary;
        string serviceType;
        string description;
        uint256 karmaReward;
        uint256 deadline;
        bool fulfilled;
        bool verified;
        uint256 fulfilledTimestamp;
    }

    struct LeaderboardEntry {
        address user;
        uint256 karma;
        AscensionTier tier;
        uint256 deedsCompleted;
    }

    uint256[10] public tierThresholds = [
        0,
        1000,
        5000,
        15000,
        50000,
        150000,
        500000,
        1500000,
        5000000,
        15000000
    ];

    uint256[10] public categoryMultipliers = [
        150, 120, 130, 140, 110, 
        125, 115, 135, 120, 200
    ];

    mapping(address => UserProfile) public profiles;
    mapping(uint256 => ServiceContract) public contracts;
    mapping(address => uint256[]) public userContracts;
    mapping(DeedCategory => uint256) public categoryDeedCount;

    uint256 public contractCounter;
    uint256 public currentSeason;
    uint256 public seasonStartTime;
    uint256 public constant SEASON_DURATION = 30 days;
    uint256 public constant STREAK_BONUS_BPS = 200;
    uint256 public constant MAX_STREAK_MULTIPLIER = 500;

    address[] public allUsers;
    mapping(address => bool) private isRegistered;

    event DeedRecorded(
        address indexed user,
        DeedCategory category,
        uint256 karmaEarned,
        uint256 newTotal
    );
    event TierAscended(
        address indexed user,
        AscensionTier oldTier,
        AscensionTier newTier
    );
    event ContractCreated(
        uint256 indexed contractId,
        address provider,
        address beneficiary
    );
    event ContractFulfilled(
        uint256 indexed contractId,
        uint256 karmaAwarded
    );
    event SeasonAdvanced(uint256 newSeason, uint256 timestamp);
    event StreakUpdated(address indexed user, uint256 newStreak);

    constructor(address _maToken) {
        require(_maToken != address(0), "Invalid token address");
        maToken = IMaToken(_maToken);
        _grantRole(DEFAULT_ADMIN_ROLE, msg.sender);
        _grantRole(VERIFIER_ROLE, msg.sender);
        currentSeason = 1;
        seasonStartTime = block.timestamp;
    }

    function recordDeed(
        address _user,
        DeedCategory _category,
        string calldata _description,
        uint256 _baseKarma
    ) external onlyRole(VERIFIER_ROLE) whenNotPaused nonReentrant {
        require(_user != address(0), "Invalid user");
        require(_baseKarma > 0, "Karma must be positive");

        if (!isRegistered[_user]) {
            isRegistered[_user] = true;
            allUsers.push(_user);
            profiles[_user].isActive = true;
            profiles[_user].seasonMultiplier = 100;
        }

        UserProfile storage profile = profiles[_user];

        uint256 categoryBonus = (
            _baseKarma * categoryMultipliers[uint256(_category)]
        ) / 100;

        uint256 streakBonus = 0;
        if (
            block.timestamp - profile.lastActivityTimestamp < 1 days &&
            profile.lastActivityTimestamp > 0
        ) {
            profile.streak++;
            uint256 streakMult = profile.streak * STREAK_BONUS_BPS;
            if (streakMult > MAX_STREAK_MULTIPLIER) {
                streakMult = MAX_STREAK_MULTIPLIER;
            }
            streakBonus = (categoryBonus * streakMult) / 10000;
            emit StreakUpdated(_user, profile.streak);
        } else if (
            block.timestamp - profile.lastActivityTimestamp > 2 days
        ) {
            profile.streak = 1;
        }

        uint256 tierBonus = (
            categoryBonus * uint256(profile.tier) * 50
        ) / 1000;

        uint256 totalKarma = categoryBonus + streakBonus + tierBonus;

        profile.totalKarma += totalKarma;
        profile.currentSeasonKarma += totalKarma;
        profile.deedsCompleted++;
        profile.lastActivityTimestamp = block.timestamp;

        categoryDeedCount[_category]++;

        _checkAscension(_user);

        string memory catName = _getCategoryName(_category);
        maToken.awardKarma(_user, totalKarma, catName, _description);

        emit DeedRecorded(_user, _category, totalKarma, profile.totalKarma);
    }

    function createServiceContract(
        address _beneficiary,
        string calldata _serviceType,
        string calldata _description,
        uint256 _karmaReward,
        uint256 _deadline
    ) external whenNotPaused nonReentrant returns (uint256) {
        require(_beneficiary != address(0), "Invalid beneficiary");
        require(_deadline > block.timestamp, "Deadline must be future");
        require(_karmaReward > 0, "Reward must be positive");

        contractCounter++;

        contracts[contractCounter] = ServiceContract({
            id: contractCounter,
            provider: msg.sender,
            beneficiary: _beneficiary,
            serviceType: _serviceType,
            description: _description,
            karmaReward: _karmaReward,
            deadline: _deadline,
            fulfilled: false,
            verified: false,
            fulfilledTimestamp: 0
        });

        userContracts[msg.sender].push(contractCounter);
        userContracts[_beneficiary].push(contractCounter);

        emit ContractCreated(contractCounter, msg.sender, _beneficiary);
        return contractCounter;
    }

    function fulfillContract(
        uint256 _contractId
    ) external onlyRole(VERIFIER_ROLE) whenNotPaused nonReentrant {
        ServiceContract storage sc = contracts[_contractId];
        require(!sc.fulfilled, "Already fulfilled");
        require(sc.id > 0, "Contract does not exist");

        sc.fulfilled = true;
        sc.verified = true;
        sc.fulfilledTimestamp = block.timestamp;

        UserProfile storage providerProfile = profiles[sc.provider];
        providerProfile.contractsFulfilled++;

        string memory catName = "SERVICE_CONTRACT";
        maToken.awardKarma(
            sc.provider, 
            sc.karmaReward, 
            catName, 
            sc.description
        );

        emit ContractFulfilled(_contractId, sc.karmaReward);
    }

    function advanceSeason() external onlyRole(DEFAULT_ADMIN_ROLE) {
        require(
            block.timestamp >= seasonStartTime + SEASON_DURATION,
            "Season not ended"
        );
        currentSeason++;
        seasonStartTime = block.timestamp;

        for (uint256 i = 0; i < allUsers.length; i++) {
            profiles[allUsers[i]].currentSeasonKarma = 0;
        }

        emit SeasonAdvanced(currentSeason, block.timestamp);
    }

    function _checkAscension(address _user) internal {
        UserProfile storage profile = profiles[_user];
        AscensionTier oldTier = profile.tier;

        for (uint256 i = 9; i > 0; i--) {
            if (profile.totalKarma >= tierThresholds[i]) {
                if (uint256(profile.tier) < i) {
                    profile.tier = AscensionTier(i);
                    emit TierAscended(_user, oldTier, profile.tier);
                }
                break;
            }
        }
    }

    function _getCategoryName(
        DeedCategory _cat
    ) internal pure returns (string memory) {
        if (_cat == DeedCategory.ENVIRONMENT) return "ENVIRONMENT";
        if (_cat == DeedCategory.SOCIETY) return "SOCIETY";
        if (_cat == DeedCategory.EDUCATION) return "EDUCATION";
        if (_cat == DeedCategory.HEALTH) return "HEALTH";
        if (_cat == DeedCategory.SPIRITUALITY) return "SPIRITUALITY";
        if (_cat == DeedCategory.TECHNOLOGY) return "TECHNOLOGY";
        if (_cat == DeedCategory.ECONOMY) return "ECONOMY";
        if (_cat == DeedCategory.GOVERNANCE) return "GOVERNANCE";
        if (_cat == DeedCategory.COMMUNITY) return "COMMUNITY";
        if (_cat == DeedCategory.CHARITY) return "CHARITY";
        return "UNKNOWN";
    }

    function getTopLeaderboard(
        uint256 _count
    ) external view returns (LeaderboardEntry[] memory) {
        uint256 count = _count > allUsers.length 
            ? allUsers.length 
            : _count;
        LeaderboardEntry[] memory entries = new LeaderboardEntry[](count);

        address[] memory sorted = new address[](allUsers.length);
        for (uint256 i = 0; i < allUsers.length; i++) {
            sorted[i] = allUsers[i];
        }

        for (uint256 i = 0; i < count; i++) {
            uint256 maxIdx = i;
            for (uint256 j = i + 1; j < sorted.length; j++) {
                if (
                    profiles[sorted[j]].totalKarma > 
                    profiles[sorted[maxIdx]].totalKarma
                ) {
                    maxIdx = j;
                }
            }
            if (maxIdx != i) {
                address temp = sorted[i];
                sorted[i] = sorted[maxIdx];
                sorted[maxIdx] = temp;
            }
            entries[i] = LeaderboardEntry({
                user: sorted[i],
                karma: profiles[sorted[i]].totalKarma,
                tier: profiles[sorted[i]].tier,
                deedsCompleted: profiles[sorted[i]].deedsCompleted
            });
        }
        return entries;
    }

    function getUserContractCount(
        address _user
    ) external view returns (uint256) {
        return userContracts[_user].length;
    }

    function getTotalUsers() external view returns (uint256) {
        return allUsers.length;
    }
}

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/access/Ownable.sol";
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";
import "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";

contract SwapRouter is Ownable, ReentrancyGuard {
    using SafeERC20 for IERC20;

    struct SwapPair {
        address tokenA;
        address tokenB;
        uint256 rateAtoB;
        uint256 rateBtoA;
        uint256 feeBps;
        bool active;
        uint256 totalVolumeA;
        uint256 totalVolumeB;
    }

    struct SwapRecord {
        address user;
        address tokenIn;
        address tokenOut;
        uint256 amountIn;
        uint256 amountOut;
        uint256 fee;
        uint256 timestamp;
    }

    mapping(bytes32 => SwapPair) public swapPairs;
    SwapRecord[] public swapHistory;
    bytes32[] public pairKeys;

    address public feeCollector;
    uint256 public defaultFeeBps = 30;

    event PairCreated(
        address indexed tokenA, 
        address indexed tokenB, 
        uint256 rate
    );
    event SwapExecuted(
        address indexed user,
        address tokenIn,
        address tokenOut,
        uint256 amountIn,
        uint256 amountOut,
        uint256 fee
    );

    constructor(address _feeCollector) Ownable(msg.sender) {
        require(_feeCollector != address(0), "Invalid fee collector");
        feeCollector = _feeCollector;
    }

    function createPair(
        address _tokenA,
        address _tokenB,
        uint256 _rateAtoB,
        uint256 _rateBtoA,
        uint256 _feeBps
    ) external onlyOwner {
        require(_tokenA != address(0) && _tokenB != address(0), "Invalid");
        require(_tokenA != _tokenB, "Same token");
        require(_rateAtoB > 0 && _rateBtoA > 0, "Invalid rates");

        bytes32 key = keccak256(abi.encodePacked(_tokenA, _tokenB));
        require(!swapPairs[key].active, "Pair exists");

        swapPairs[key] = SwapPair({
            tokenA: _tokenA,
            tokenB: _tokenB,
            rateAtoB: _rateAtoB,
            rateBtoA: _rateBtoA,
            feeBps: _feeBps > 0 ? _feeBps : defaultFeeBps,
            active: true,
            totalVolumeA: 0,
            totalVolumeB: 0
        });

        pairKeys.push(key);
        emit PairCreated(_tokenA, _tokenB, _rateAtoB);
    }

    function swap(
        address _tokenIn,
        address _tokenOut,
        uint256 _amountIn
    ) external nonReentrant returns (uint256 amountOut) {
        require(_amountIn > 0, "Zero amount");

        bytes32 key1 = keccak256(abi.encodePacked(_tokenIn, _tokenOut));
        bytes32 key2 = keccak256(abi.encodePacked(_tokenOut, _tokenIn));

        SwapPair storage pair;
        uint256 rate;

        if (swapPairs[key1].active) {
            pair = swapPairs[key1];
            rate = pair.rateAtoB;
            pair.totalVolumeA += _amountIn;
        } else if (swapPairs[key2].active) {
            pair = swapPairs[key2];
            rate = pair.rateBtoA;
            pair.totalVolumeB += _amountIn;
        } else {
            revert("Pair not found");
        }

        uint256 fee = (_amountIn * pair.feeBps) / 10000;
        uint256 netAmount = _amountIn - fee;
        amountOut = (netAmount * rate) / 10**18;

        require(amountOut > 0, "Output too small");

        IERC20(_tokenIn).safeTransferFrom(msg.sender, address(this), _amountIn);

        if (fee > 0) {
            IERC20(_tokenIn).safeTransfer(feeCollector, fee);
        }

        require(
            IERC20(_tokenOut).balanceOf(address(this)) >= amountOut,
            "Insufficient liquidity"
        );

        IERC20(_tokenOut).safeTransfer(msg.sender, amountOut);

        swapHistory.push(SwapRecord({
            user: msg.sender,
            tokenIn: _tokenIn,
            tokenOut: _tokenOut,
            amountIn: _amountIn,
            amountOut: amountOut,
            fee: fee,
            timestamp: block.timestamp
        }));

        emit SwapExecuted(
            msg.sender, 
            _tokenIn, 
            _tokenOut, 
            _amountIn, 
            amountOut, 
            fee
        );
    }

    function addLiquidity(
        address _token,
        uint256 _amount
    ) external onlyOwner {
        IERC20(_token).safeTransferFrom(msg.sender, address(this), _amount);
    }

    function updateRate(
        address _tokenA,
        address _tokenB,
        uint256 _newRateAtoB,
        uint256 _newRateBtoA
    ) external onlyOwner {
        bytes32 key = keccak256(abi.encodePacked(_tokenA, _tokenB));
        require(swapPairs[key].active, "Pair not found");
        swapPairs[key].rateAtoB = _newRateAtoB;
        swapPairs[key].rateBtoA = _newRateBtoA;
    }

    function getSwapHistoryLength() external view returns (uint256) {
        return swapHistory.length;
    }

    function getPairCount() external view returns (uint256) {
        return pairKeys.length;
    }
}

    .option(
        "--interval <ms>",
        "Loop interval in milliseconds",
        "5000"
    )
    .action(async (options) => {
        const spinner = ora("Initializing loop engine...").start();
        try {
            const registryPath = path.join(
                PROJECT_ROOT,
                "bots",
                "registry",
                "bot-registry.json"
            );

            if (!(await fs.pathExists(registryPath))) {
                spinner.fail(
                    chalk.red(
                        "No bots deployed. Run `melodie bot:deploy` first."
                    )
                );
                return;
            }

            const registry = await fs.readJson(registryPath);
            const activeBots = registry.bots.filter(
                (b) => b.status === "ACTIVE"
            );

            const botCount =
                options.bots === "all"
                    ? activeBots.length
                    : Math.min(parseInt(options.bots), activeBots.length);

            spinner.succeed(
                chalk.green(
                    `Loop engine started with ${botCount} bot(s)!`
                )
            );

            console.log(
                chalk.cyan(
                    "\n═══════════════════════════════════════"
                )
            );
            console.log(
                chalk.cyan(
                    "  BOT REVENUE AUTOMATION ENGINE ACTIVE"
                )
            );
            console.log(
                chalk.cyan(
                    "═══════════════════════════════════════\n"
                )
            );

            const interval = parseInt(options.interval);
            let cycleCount = 0;

            const loopEngine = setInterval(async () => {
                cycleCount++;
                const timestamp = new Date().toISOString();

                const taskTypes = [
                    "PRODUCT_SALE",
                    "SERVICE_FULFILLMENT",
                    "CONTRACT_SIGNING",
                    "KARMA_DEED",
                    "TREASURY_SYNC",
                ];

                const selectedTask =
                    taskTypes[cycleCount % taskTypes.length];

                console.log(
                    chalk.gray(`[${timestamp}]`) +
                        chalk.green(` Cycle #${cycleCount}`) +
                        chalk.yellow(` | Task: ${selectedTask}`) +
                        chalk.cyan(` | Active Bots: ${botCount}`)
                );

                const earningsPath = path.join(
                    REVENUE_DATA_PATH,
                    "earnings.json"
                );
                await fs.ensureDir(REVENUE_DATA_PATH);

                let earnings = {
                    totalRevenue: "0",
                    cycles: 0,
                    history: [],
                };
                if (await fs.pathExists(earningsPath)) {
                    earnings = await fs.readJson(earningsPath);
                }

                earnings.cycles = cycleCount;
                earnings.lastUpdate = timestamp;
                earnings.history.push({
                    cycle: cycleCount,
                    task: selectedTask,
                    botCount: botCount,
                    timestamp: timestamp,
                });

                if (earnings.history.length > 10000) {
                    earnings.history = earnings.history.slice(-10000);
                }

                await fs.writeJson(earningsPath, earnings, {
                    spaces: 2,
                });
            }, interval);

            process.on("SIGINT", () => {
                clearInterval(loopEngine);
                console.log(
                    chalk.yellow(
                        `\nEngine stopped after ${cycleCount} cycles.`
                    )
                );
                process.exit(0);
            });
        } catch (error) {
            spinner.fail(
                chalk.red(`Engine start failed: ${error.message}`)
            );
        }
    });

class GasEstimatorClass {
    static async estimate(provider, to, amount, token) {
        try {
            const feeData = await provider.getFeeData();
            const gasLimit =
                token === "ETH" ? 21000n : 65000n;
            return {
                gasLimit: gasLimit,
                gasPrice: ethers.formatUnits(
                    feeData.gasPrice || 0n,
                    "gwei"
                ),
                maxFeePerGas: feeData.maxFeePerGas
                    ? ethers.formatUnits(
                          feeData.maxFeePerGas,
                          "gwei"
                      )
                    : "N/A",
                estimatedCost: ethers.formatEther(
                    gasLimit *
                        (feeData.gasPrice || 0n)
                ),
            };
        } catch (error) {
            return {
                gasLimit: 65000n,
                gasPrice: "20",
                maxFeePerGas: "N/A",
                estimatedCost: "0.0013",
            };
        }
    }

                    method: "eth_accounts",
                });
                if (accounts.length > 0) {
                    setWalletAddress(accounts[0]);
                    setWalletConnected(true);
                    await loadBalances(accounts[0]);
                    await loadKarmaData(accounts[0]);

                console.error("Wallet check failed:", error);

                    method: "eth_requestAccounts",

                setWalletConnected(true);
                await loadBalances(accounts[0]);

            alert("Fill all fields");
            return;
        }

            if (sendToken === "ETH") {

                    method: "eth_sendTransaction",
                    params: [

                            from: address,
                            to: sendTo,
                            value:
                                "0x" +
                                (
                                    parseFloat(sendAmount) *
                                    1e18
                                )
                                    .toString(16),
                        },
                    ],
                });
                alert(`Transaction sent: ${txHash}`);
            } else {
                alert(
                    `Token transfer for ${sendToken} requires contract interaction. Use CLI: melodie wallet:send`
                );
            }
        } catch (error) {
            alert(`Transaction failed: ${error.message}`);
        }
    }

    return (
        <div className="wallet-panel">
            <h2 className="section-title">
                💰 MetaMello Wallet
            </h2>

                <div className="connect-prompt">
                    <p>

import React, { useState, useEffect, useRef } from "react";

function MiningPanel({ active, onToggle }) {
    const [miningLog, setMiningLog] = useState([]);
    const [totalMined, setTotalMined] = useState(0);
    const [intensity, setIntensity] = useState("medium");
    const intervalRef = useRef(null);

    const categories = [
        "ENVIRONMENT",
        "SOCIETY",
        "EDUCATION",
        "HEALTH",
        "SPIRITUALITY",
        "TECHNOLOGY",
        "ECONOMY",
        "GOVERNANCE",
        "COMMUNITY",
        "CHARITY",
    ];

    const intensityConfig = {
        low: { interval: 10000, multiplier: 1 },
        medium: { interval: 5000, multiplier: 2 },
        high: { interval: 2000, multiplier: 5 },
    };

    useEffect(() => {
        if (active) {
            const config = intensityConfig[intensity];
            intervalRef.current = setInterval(() => {
                const category =
                    categories[
                        Math.floor(
                            Math.random() * categories.length
                        )
                    ];
                const baseKarma =
                    Math.floor(Math.random() * 100) + 10;
                const karma = baseKarma * config.multiplier;
                const maTokens = karma / 100;

                setTotalMined((prev) => prev + karma);

                setMiningLog((prev) => {
                    const newLog = [
                        {
                            timestamp: new Date().toLocaleTimeString(),
                            category,
                            karma,
                            maTokens: maTokens.toFixed(2),
                        },
                        ...prev,
                    ].slice(0, 100);
                    return newLog;
                });
            }, config.interval);
        } else {
            if (intervalRef.current) {
                clearInterval(intervalRef.current);
            }
        }

        return () => {
            if (intervalRef.current) {
                clearInterval(intervalRef.current);
            }
        };
    }, [active, intensity]);

    return (
        <div className="mining-panel">
            <h2 className="section-title">
                ⛏️ MA Token Karma Mining
            </h2>

            <div className="mining-controls">
                <div className="mining-status-display">
                    <span
                        className={`status-indicator ${
                            active ? "active" : "inactive"
                        }`}
                    >
                        {active
                            ? "🟢 MINING ACTIVE"
                            : "🔴 MINING INACTIVE"}
                    </span>
                </div>

                <div className="intensity-selector">
                    <label>Mining Intensity:</label>
                    <div className="intensity-buttons">
                        {["low", "medium", "high"].map(
                            (level) => (
                                <button
                                    key={level}
                                    className={`intensity-btn ${
                                        intensity === level
                                            ? "selected"
                                            : ""
                                    }`}
                                    onClick={() =>
                                        setIntensity(level)
                                    }
                                >
                                    {level.toUpperCase()}
                                </button>
                            )
                        )}
                    </div>
                </div>

                <button
                    className={`mining-toggle-btn ${
                        active ? "stop" : "start"
                    }`}
                    onClick={onToggle}
                >
                    {active
                        ? "⏹️ Stop Mining"
                        : "⛏️ START-MA-TOKEN-MINING"}
                </button>
            </div>

            <div className="mining-stats">
                <div className="mining-stat">
                    <span>Total Karma Mined</span>
                    <span className="stat-number">
                        {totalMined.toLocaleString()}
                    </span>
                </div>
                <div className="mining-stat">
                    <span>MA Tokens Earned</span>
                    <span className="stat-number">
                        {(totalMined / 100).toFixed(2)}
                    </span>
                </div>
                <div className="mining-stat">
                    <span>Mining Entries</span>
                    <span className="stat-number">
                        {miningLog.length}
                    </span>
                </div>
            </div>

            <div className="mining-log">
                <h3>Mining Log</h3>
                <div className="log-container">
                    {miningLog.length === 0 ? (
                        <p className="log-empty">
                            Start mining to see activity
                            here.
                        </p>
                    ) : (
                        miningLog.map((entry, idx) => (
                            <div
                                key={idx}
                                className="log-entry"
                            >
                                <span className="log-time">
                                    {entry.timestamp}
                                </span>
                                <span className="log-category">
                                    {entry.category}
                                </span>
                                <span className="log-karma">
                                    +{entry.karma} karma
                                </span>
                                <span className="log-ma">
                                    →{" "}
                                    {entry.maTokens} MA
                                </span>
                            </div>
                        ))
                    )}
                </div>
            </div>
        </div>
    );
}

export default MiningPanel;

async function main() {
    const [deployer] = await ethers.getSigners();

        "ETH"

    const deployedAddresses = {};

    // 1. Deploy MaToken
    console.log("\n[1/6] Deploying MaToken...");
    const MaToken = await ethers.getContractFactory("MaToken");
    const maToken = await MaToken.deploy(deployer.address);
    await maToken.waitForDeployment();
    const maTokenAddress = await maToken.getAddress();
    deployedAddresses.MaToken = maTokenAddress;
    console.log("MaToken deployed:", maTokenAddress);

    // 2. Deploy KarmaPowerPoint
    console.log("\n[2/6] Deploying KarmaPowerPoint...");
    const KarmaPowerPoint = await ethers.getContractFactory(
        "KarmaPowerPoint"
    );
    const karmaPP = await KarmaPowerPoint.deploy(maTokenAddress);
    await karmaPP.waitForDeployment();
    const karmaAddress = await karmaPP.getAddress();
    deployedAddresses.KarmaPowerPoint = karmaAddress;
    console.log("KarmaPowerPoint deployed:", karmaAddress);

    // 3. Deploy MetaMelloTreasury
    console.log("\n[3/6] Deploying MetaMelloTreasury...");
    const Treasury = await ethers.getContractFactory(
        "MetaMelloTreasury"
    );
    const treasury = await Treasury.deploy(maTokenAddress);
    await treasury.waitForDeployment();
    const treasuryAddress = await treasury.getAddress();
    deployedAddresses.MetaMelloTreasury = treasuryAddress;
    console.log("Treasury deployed:", treasuryAddress);

    // 4. Deploy SwapRouter
    console.log("\n[4/6] Deploying SwapRouter...");
    const SwapRouter = await ethers.getContractFactory(
        "SwapRouter"
    );
    const swapRouter = await SwapRouter.deploy(
        deployer.address
    );
    await swapRouter.waitForDeployment();
    const swapAddress = await swapRouter.getAddress();
    deployedAddresses.SwapRouter = swapAddress;
    console.log("SwapRouter deployed:", swapAddress);

    // 5. Grant roles
    console.log("\n[5/6] Configuring roles...");
    const KARMA_ENGINE_ROLE = ethers.keccak256(
        ethers.toUtf8Bytes("KARMA_ENGINE_ROLE")
    );
    await maToken.grantRole(KARMA_ENGINE_ROLE, karmaAddress);
    console.log("Granted KARMA_ENGINE_ROLE to KarmaPowerPoint");

    const TREASURY_ROLE = ethers.keccak256(
        ethers.toUtf8Bytes("TREASURY_ROLE")
    );
    await maToken.grantRole(TREASURY_ROLE, treasuryAddress);
    console.log("Granted TREASURY_ROLE to Treasury");

    // 6. Save deployment
    console.log("\n[6/6] Saving deployment data...");
    const deployment = {
        network: (await ethers.provider.getNetwork()).name,
        chainId: Number(
            (await ethers.provider.getNetwork()).chainId
        ),
        deployer: deployer.address,
        timestamp: new Date().toISOString(),
        contracts: deployedAddresses,

        __dirname,
        "..",
        "deployments"
    );

    await fs.writeJson(
        path.join(deployDir, "latest.json"),
        deployment,
        { spaces: 2 }
    );

    console.log("  DEPLOYMENT COMPLETE");
    console.log("══════════════════════════════════════");
