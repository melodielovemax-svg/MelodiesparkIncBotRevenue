# Path of Melodie: MAAKARA Protocols — 45-Class Ascension System

## Structure

- **45 total playable classes/characters**.
- **7 Starting Origins** remain available through normal character creation.
- **38 characters/classes are permanent account unlocks earned through deep-endgame Ascension and verified Karma Power Point progression.**
- KPP is an eligibility/progression requirement; unlocking a class does **not spend or trade KPP**.
- All KPP thresholds below are **design targets, not balance-tested values**.

## Ascension Rule

`Origin → Endgame → Karma Pillar Mastery → KPP Threshold → Ascension Trial → Sovereign Encounter → Verified Completion → Permanent Character Unlock`

Unlock validation must be server-authoritative if online services are enabled. Client-side KPP values must never directly unlock an Ascension character.
