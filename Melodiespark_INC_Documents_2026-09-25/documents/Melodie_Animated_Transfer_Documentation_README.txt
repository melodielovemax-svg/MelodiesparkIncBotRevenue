MELODIE ANIMATED TRANSFER DOCUMENTATION — GDEVELOP

Open Melodie_Animated_Transfer_Documentation.gdevelop in GDevelop.

Controls:
ENTER  = open documentation / continue
SPACE  = run transfer sequence
ESC    = return to transfer hub
R      = restart after completion

Scenes:
1. TransferHub
2. Documentation
3. Transfer
4. Complete

Design:
- 1280x720 landscape
- neon/cyber transfer-console presentation
- Tween-based title/card/status animations
- embedded transfer documentation
- keyboard navigation
- no external assets required

This is an editable starter project. After opening it in your installed
GDevelop version, save once from the editor so GDevelop can migrate the
project metadata/schema to the exact version you are running.
