
# Path OF Melodie — Maakaras Protocols — 15 Act ARPG

This is an original Godot 4 playable foundation inspired by the *genre* of isometric loot-driven action RPGs. It is not the proprietary Path of Exile 2 engine and does not contain PoE2 assets, code, trademarks, or copied content.

## Controls
WASD / arrows = move
LMB = basic attack
1-4 = skills
Q = Guardian pulse
SPACE = Phoenix Ascension when XP is full

## 15-act campaign
1. Ashes of Aurelion
2. The Broken Guardian
3. Cathedral of Lost Souls
4. Pyra, Land of Fire
5. The Frozen Oath
6. The Corrupted Choir

9. The Soul Sea
10. The Phoenix Prison
11. Return of the First Soul

13. Paradise Reborn
14. The Last Ascension
15. Phoenix Eternal

## Production architecture
Client: Godot now; Unreal can be substituted for the production 3D client.
Backend: authoritative server, accounts, persistence, inventory, economy, matchmaking.
Game systems: combat, skills, items, crafting, Soul Core, Guardians, Arc-Angels, Karma, Ascension, procedural endgame.
Economy: local game currencies first. Any external digital-asset system must be separately designed, legally reviewed and never require custody of player private keys.
