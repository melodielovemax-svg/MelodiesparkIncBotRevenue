# Path OF Melodie — Shattering Core

A Godot 4 combat-system module for the Path OF Melodie 3D ARPG.

This is designed to be copied into:

`MelodiesparkCommandCenter/game/`

It provides reusable Hitbox3D, Hurtbox3D, DamagePacket, ShatteringCore, SkillProfile, ImpactRouter and ShatterFX components.

It is not a complete game or a replacement for the current vertical slice. Integrate the components into the existing scenes and connect the signals to the current player/enemy/VFX systems.
