# Compliance boundary

Le package ne constitue pas un avis juridique ou réglementaire.

Avant toute activation financière ou trading réel, il faut documenter :

- juridiction et activités concernées ;
- obligations KYC/AML ou sanctions si applicables ;
- identité et MFA ;
- limites, moteur de risque et revue humaine ;
- conservation des données ;
- récupération et réponse aux incidents ;
- obligations fiscales ;
- fournisseurs et sous-traitants ;
- politique de conservation et de suppression.

Le statut par défaut est `blocked` ou `out_of_scope` tant que ces éléments ne sont pas approuvés.
