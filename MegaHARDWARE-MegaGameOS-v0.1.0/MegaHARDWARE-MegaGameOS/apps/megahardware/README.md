# MegaHARDWARE

MegaHARDWARE is a host-performance observation and virtualization-planning layer.

Pipeline:

DISCOVER HARDWARE
-> BENCHMARK
-> MEASURE
-> VALIDATE
-> STORE EVIDENCE
-> BUILD PERFORMANCE PROFILE
-> APPLY VIRTUAL PROFILE
-> RE-BENCHMARK

It does not extract hidden performance from hardware, create money/value from benchmark numbers,
or magically exceed physical limits. Virtual profiles are software scheduling/configuration profiles.
