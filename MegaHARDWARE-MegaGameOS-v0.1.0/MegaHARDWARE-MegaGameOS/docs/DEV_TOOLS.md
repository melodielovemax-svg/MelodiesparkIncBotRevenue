# Developer Toolchain

Recommended detection/bootstrap targets:

- Git
- PowerShell 7
- Node.js LTS + npm
- Python 3
- CMake
- Ninja
- LLVM/Clang
- Rust/Cargo
- Go
- Docker
- VS Code
- Visual Studio Build Tools
- Windows SDK
- Ollama

The bootstrap script detects installed tools but does not silently download software or execute privileged installers.
