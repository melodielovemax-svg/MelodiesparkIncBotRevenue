# Evidence Governance

OPERATIONAL = implemented + tested + runtime verified
SCAFFOLD = local architecture/logic exists but integration evidence is incomplete
UNVERIFIED = requires external/runtime evidence
PLANNED = not implemented
BLOCKED = deliberately disabled by policy
FICTIONAL = must never be represented as real

A virtual performance score is not a claim of physically possessing the referenced hardware.
A game registry entry is not proof that a game is installed or licensed.
A chatbot registry entry is not proof that the provider is connected.
