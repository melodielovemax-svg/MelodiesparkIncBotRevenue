# MELODIESPARK: THE LONG SONG — CANON DOCUMENTAIRE

Ce dossier contient le canon narratif de _Melodiespark: The Long Song_.

> Melodiespark INC est le cadre produit réel. _The Long Song_ est l’univers fictif du jeu. Le lore peut guider l’évolution du produit et du jeu, mais ne décrit pas l’histoire, l’exploitation ou les capacités réelles de Melodiespark INC.

## Principe d’utilisation

```text
Code existant
   ↓
Exigences
   ↓
Tests et architecture
   ↓
Extension de données
   ↓
Persistance
   ↓
Intégration du lore
```

Le lore ne remplace pas le code, les tests ou la documentation produit. Toute évolution doit préserver la compatibilité, expliciter ses hypothèses et laisser une trace dans les documents concernés.
