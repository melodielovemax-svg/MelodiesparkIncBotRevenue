# Karma / MA Token Policy

Karma points and blockchain assets are separate concepts.

A Karma point has no monetary value merely because the application displays it.

Conversion into blockchain assets requires verified:

- legal/compliance review
- conversion mechanism
- supported jurisdiction
- rate source
- fees
- authorization
- blockchain transaction
- receipt
- accounting reconciliation

Until independently verified, conversion remains:

PLANNED
PAPER-ONLY
BLOCKED
or
UNVERIFIED
