# PATH OF MELODIE — 30,000-PICTURE ARTWORK PRODUCTION PACKAGE

## Important status
This package defines a 30,000-image production corpus and its generation/QA manifest. It does not falsely claim that 30,000 finished image files have already been rendered.

## Art direction
Original dark-fantasy/isometric ARPG identity; cinematic AAA fantasy presentation; dark early campaign evolving toward luminous/hopeful Phoenix imagery.

## Corpus allocation
1. Characters & heroes — 4,000
2. Enemies & creatures — 4,000
3. Bosses & elites — 2,000
4. Environments & biomes — 5,000
5. Items & equipment — 5,000
6. Skills/VFX concepts — 2,500
7. UI/HUD/icon concepts — 1,500
8. Cinematic/story keyframes — 2,000
9. NPCs/factions/props — 2,000
10. Marketing/key art/concept sheets — 2,000

TOTAL = 30,000

## Naming
POM_ART_<CATEGORY>_<SUBCATEGORY>_<000001..030000>

## Prompt principles
- original Path of Melodie visual language
- isometric readability when gameplay-facing
- strong silhouette
- production-friendly composition
- no copied franchise characters
- no logos from reference games
- no direct recreation of proprietary game screenshots
- separate concept-art and final-game asset statuses

## Production states
PLANNED -> GENERATED -> REVIEW -> APPROVED -> ENGINE_IMPORT -> INTEGRATED -> VERIFIED

Only INTEGRATED + VERIFIED means the asset is proven inside Unreal.

## Suggested batches
300 batches x 100 assets.
Each batch gets:
- manifest
- prompts
- generated images
- review sheet
- rejected list
- approved list
- engine import notes
